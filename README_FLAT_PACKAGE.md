# City-Metro FCD Reproducibility Package (Flat Version)

This archive is reorganised for GitHub and Zenodo upload.

## Structure

All files are stored at the root level. No subfolders are used. Original path information is preserved in each filename using double underscores (`__`).

## Size control

Each top-level file in this archive is below 20 MB. Large OSM GeoJSON files above 20 MB in the original package were compressed as individual `.zip` files. Raw TomTom screenshots were excluded from this public upload package because provider screenshots may have redistribution restrictions.

## Content

The archive retains processed indicator tables, validation files, scripts, documentation, public/open raw boundary files, OSM road-edge files, and population/vehicle proxy files. It is intended as a reproducibility package for reported calculations, not as redistribution of proprietary raw platform content.
